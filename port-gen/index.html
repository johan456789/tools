port-gen

Generate user port (1024-49151) from a project name using CRC-32.

How it works
  1. Compute CRC-32 (IEEE, polynomial 0xEDB88320) of the UTF-8 bytes of the exact project name (case-sensitive, spaces count).
  2. Take the unsigned decimal representation, e.g. 1234567890.
  3. Slide a 4-digit window from right to left; the first window in range 1024–49151 wins.
  4. If none match, repeat with a 5-digit window.
  5. If still nothing matches, no deterministic port can be generated.
Note
  • Speed: ~2M lookups/sec in Node — a single lookup in the browser is instant.
  • Collisions: if you generate ports for 1000 projects, with 8976 possible ports, the birthday paradox predicts 1000²/(2×8976) = 55.7 colliding pairs. This is good enough for homelab.

Measured hit rates of this algorithm over 2M enumerated names (bench-0 … bench-1999999):

  • 89.8% match on the first (rightmost) 4-digit window.
  • 10.2% slide left within the 4-digit windows (mostly windows with leading zeros).
  • 5-digit fallback triggered 8 times in 2M (~0.0004%).
  • 0 total failures in this run; across runs roughly ~1 in 2M (only when the CRC has fewer than 4 digits or every window misses).
